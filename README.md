QA Approach

My manual-testing workflow is:

Understand requirements and acceptance criteria

Identify test scenarios and edge cases

Create structured test cases

Execute functional, usability, compatibility, and regression checks

Record expected vs. actual results

Log reproducible defects with clear evidence

Retest fixes

Summarize test coverage, defects, blockers, and recommendations
