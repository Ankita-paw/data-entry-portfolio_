# Sample Bug Report

> Portfolio demonstration only. This is not a report from a real client system.

**Title:** Demo checkout button remains disabled after valid required fields are completed

**Environment:** Demonstration web application; desktop browser; test data only.

**Precondition:** User is on the demo checkout page.

**Steps to Reproduce**
1. Open the demo checkout page.
2. Complete all mandatory fields with valid test data.
3. Review the checkout action.

**Expected Result**
The checkout action becomes available when all mandatory inputs are valid.

**Actual Result**
The button remains unavailable despite all required fields being completed.

**Severity:** Medium (sample classification)

**Priority:** To be confirmed by the product/team.

**Evidence:** Screenshot/video would be attached during real execution.

**Suggested QA follow-up**
- Reproduce in another supported browser.
- Check browser console/network behavior if appropriate.
- Retest after the fix.
- Run regression checks on the checkout flow.
